# 학교 기자재 관리 시스템 운영 및 배포 매뉴얼

본 문서는 Google Sheets와 Google Apps Script 기반의 학교 기자재 관리 시스템을 성공적으로 배포하고, 출력용 기기관리 라벨지를 오차 없이 인쇄하여 운영할 수 있도록 돕는 실무 가이드라인입니다.

---

## 1. 초기 배포 및 설정 절차

### 1-1. 스프레드시트 사본 제작
1. 기존에 구성된 기자재 관리 스프레드시트를 구글 드라이브에서 열고, **[파일] > [사본 만들기]**를 클릭하여 사본을 생성합니다.
2. (스프레드시트에 연동된 Apps Script 소스코드도 사본에 자동으로 함께 복제됩니다.)

### 1-2. 시스템 최초 초기화 (최초 1회 실행)
1. 복사된 구글 스프레드시트 상단 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
2. 좌측 파일 메뉴 중 `Code.gs`가 보이며, 상단 도구 모음에서 함수 목록 중 `setupSheets`를 선택합니다.
3. **[실행]** 버튼을 누릅니다.
4. 최초 실행 시 구글 계정에 대한 권한 승인 창이 팝업됩니다. **[권한 검토]**를 누르고 사용할 구글 계정을 선택한 뒤, **[Advanced(고급)] > [Go to... (안전하지 않음으로 이동)]**을 클릭하여 **[Allow(허용)]**합니다.
5. 실행이 완료되면 스프레드시트에 `[마스터]`, `[설정]`, `[기기관리라벨]` 시트가 자동 생성되며 예시 데이터가 삽입됩니다.

### 1-3. 모바일 웹앱 배포 및 권한 설정
1. Apps Script 화면 우측 상단의 **[배포] > [새 배포]**를 선택합니다.
2. 좌측 톱니바퀴 아이콘을 눌러 유형을 **[웹 앱]**으로 선택합니다.
3. 배포 설정 항목을 다음과 같이 정확하게 입력합니다:
   * **설명**: `기자재 관리 시스템 v1.0` (또는 임의 작성)
   * **웹 앱을 실행할 사용자**: `나(본인의 구글 계정)`
   * **액세스 권한이 있는 사용자**: `모든 사용자` (로그인 없이 스마트폰 QR 스캔으로 즉시 양식을 확인하고 수정하기 위해 반드시 '모든 사용자'로 설정해야 합니다.)
4. **[배포]** 버튼을 누르고, 승인 요청 시 허용합니다.
5. 배포 완료 후 화면에 표시되는 **웹 앱 URL**을 복사합니다.

### 1-4. 환경설정 값 입력
1. 복제된 구글 스프레드시트로 돌아와 **`[설정]` 시트**를 엽니다.
2. **`웹앱URL`** 항목의 값(B열)에 방금 복사한 Apps Script 웹 앱 URL을 붙여넣습니다. (예: `https://script.google.com/macros/s/XXXXX/exec`)
3. `설치장소목록`과 `취급자목록` 항목의 값(B열)을 학교 실정에 맞게 쉼표(`,`)로 구분하여 자유롭게 수정합니다.
4. PC 기종에 대한 민감 정보(IP, 비밀번호) 수정을 허용하려면 `PC민감정보수정허용` 값을 **`Y`**로 입력합니다. (기본값은 `N`이며 이 경우 노트북이나 모니터처럼 민감정보 폼이 원천 차단됩니다.)

### 1-5. QR 링크 및 이미지 갱신
1. 다시 Apps Script 편집기 화면으로 이동하여 상단 함수 목록에서 `refreshQrLinks`를 선택하고 **[실행]**을 누릅니다.
2. 실행이 완료되면 `[마스터]` 시트의 `QR링크` 열에 배포된 URL과 기기 관리번호가 연동된 주소가 자동 입력되며, `QR이미지` 열에 이미지 수식이 일괄 갱신되어 시트 안에서 QR코드를 바로 볼 수 있게 됩니다.

## 2. 기기관리 라벨지 출력 및 인쇄 요령

라벨 출력 시트는 실제 라벨지에 인쇄할 때 발생할 수 있는 오차를 방지하도록 **상하좌우 안전 여백(Safe Margin)**을 적용하여 물리적으로 설계되었습니다.

### 2-1. 라벨 시트 생성
1. Apps Script 편집기 화면 상단 함수 목록에서 `createLabelSheet`를 선택하고 **[실행]**을 누릅니다.
2. 실행이 완료되면 스프레드시트의 `[기기관리라벨]` 시트가 활성화되며, 마스터 시트의 기기 데이터를 바탕으로 **애니라벨 10칸(A4, 2열 5행)** 규격에 맞게 바둑판식 라벨 템플릿이 일괄 드로잉됩니다.
3. 개별 라벨 경계(88.9mm x 52.0mm) 내부의 안전 여백을 축소하여 핵심 정보 표 영역의 크기를 **가로 80mm, 세로 45mm**로 대폭 확대 설계하였습니다. 잘림을 예방하면서도 가득 찬 인쇄 레이아웃을 제공합니다.

### 2-2. 최적 인쇄 설정 (매우 중요)
인쇄 시 스프레드시트의 격자가 라벨 용지 경계선에 정밀하게 매칭되도록 구글 스프레드시트 인쇄창(`Ctrl + P`)에서 아래 옵션을 **반드시 일치시켜 주십시오.**

1. **인쇄 대상**: `현재 시트`
2. **용지 크기**: `A4`
3. **페이지 방향**: `세로`
4. **배율**: **`페이지 너비에 맞춤`** (또는 `100%`)
   * *권장*: 인쇄 배율을 `페이지 너비에 맞춤`으로 설정하면 대칭되는 좌우 11.5mm 여백(Col A 및 Col O 바깥)이 용지 규격과 정확하게 스케일 매칭됩니다.
5. **여백**: **`없음`** (또는 `맞춰진 여백`에서 상하좌우를 `0`으로 지정)
   * *이유*: 이미 `createLabelSheet()` 코드 자체에서 상단 여백(`77px` ≈ 20.5mm)과 좌우 여백(`43px` ≈ 11.5mm), 열 간격 및 안전 마진을 셀의 너비와 높이로 물리적으로 적용해 두었습니다. 따라서 프린터 자체에서 또 여백을 주게 되면 정렬이 어긋납니다. 여백 설정을 `없음`으로 해 주셔야 코드로 설계된 여백이 정확히 용지에 인쇄됩니다.
6. **서식**: `그리드선 표시` 체크 해제
   * 스프레드시트 자체의 점선 격자선이 인쇄물에 나오지 않도록 반드시 체크 해제해 주십시오. 코드에서 그린 짙은 회색 표 테두리와 연한 칼선용 경계 회색선만 깔끔하게 출력됩니다.
7. **머리글 및 바닥글**: 모든 항목(페이지 번호, 통합 문서 제목 등) 체크 해제

## 3. 일상 운영 및 유지보수 가이드

* **신규 기자재 등록 시**:
  1. `[마스터]` 시트 맨 아래 빈 행에 순번을 이어받아 연번, 관리번호, 종류, 취급자 등의 정보를 수동 기재합니다.
  2. Apps Script에서 `refreshQrLinks()`를 실행하여 새로 등록한 기기의 QR코드 링크와 이미지를 채웁니다.
  3. `createLabelSheet()`를 실행하여 `[기기관리라벨]` 시트를 재생성하고 인쇄하여 새 기기에 부착합니다.
* **기기 사용자 변경 및 위치 이동 시**:
  1. 기기에 부착된 QR코드를 스마트폰 카메라로 스캔합니다.
  2. 스마트폰 웹 화면에 기기 기본 정보가 조회됩니다.
  3. 설치장소와 취급자를 드롭다운에서 선택하고 특이사항이 있다면 비고란에 기재한 뒤 **[수정 내용 저장]**을 클릭합니다.
  4. 구글 스프레드시트 마스터 시트 해당 행의 데이터와 최종수정일이 실시간으로 자동 업데이트됩니다.
